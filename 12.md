# ТЗ — ПОДГОТОВКА ТЕСТОВЫХ СВЕЧЕЙ ДЛЯ PAPER-TRADING-ENGINE

## Цель

Скачать и записать в TimescaleDB правильные свечи Binance и Bybit, предоставить проекту `paper-trading-engine` SELECT-доступ и возможность поэтапно проверить подключение.

На этом этапе не менять старые таблицы, collectors, OI, funding и liquidations.

---

## 1. Тестовый объём

```text
1m — последние 3 полных UTC-дня
1h — последние 21 полный UTC-день
```

Биржи:

```text
Binance USDⓈ-M Futures
Bybit Linear USDT Perpetual
```

Символы:

```text
весь текущий активный universe отдельно для Binance и Bybit
```

Сохранять только полностью закрытые свечи.

---

## 2. Таблицы

Создать отдельные TimescaleDB hypertables:

```text
public.candles_1m_paper_test
public.candles_1h_paper_test
```

Старые candle-таблицы не удалять и не изменять.

---

## 3. Единая схема обеих таблиц

```text
exchange                 text            NOT NULL
symbol                   text            NOT NULL
interval                 text            NOT NULL
open_ts                  timestamptz     NOT NULL
close_ts                 timestamptz     NOT NULL

open                     numeric(38,18)  NOT NULL
high                     numeric(38,18)  NOT NULL
low                      numeric(38,18)  NOT NULL
close                    numeric(38,18)  NOT NULL

volume_base              numeric(38,18)  NOT NULL
volume_quote             numeric(38,18)  NOT NULL
trade_count              bigint          NULL

is_closed                boolean         NOT NULL
quality_status           text            NOT NULL

source                    text            NOT NULL
source_event_id           text            NOT NULL
source_updated_at         timestamptz     NULL
ingested_at               timestamptz     NOT NULL

checksum                  text            NOT NULL
source_contract_version   text            NOT NULL
```

Не использовать `double precision` для цен и объёмов. Значения биржи читать как строки и преобразовывать через `Decimal`.

---

## 4. Идентичность свечи

Уникальный ключ:

```text
exchange + symbol + interval + open_ts
```

Уникальное ограничение:

```text
UNIQUE (exchange, symbol, interval, open_ts)
```

Binance и Bybit — разные источники. Свечи одной биржи не должны заменять свечи другой.

---

## 5. Минутная свеча

Для `candles_1m_paper_test`:

```text
interval = '1m'
open_ts = начало UTC-минуты
close_ts = open_ts + 1 minute
is_closed = true
quality_status = 'COMPLETE'
```

Текущую открытую минуту не сохранять.

Источники:

```text
Binance REST native 1m
Bybit REST native 1m
```

Поля Binance:

```text
open_ts      = open time
OHLC         = native OHLC
volume_base  = base asset volume
volume_quote = quote asset volume
trade_count  = trade count
```

Поля Bybit:

```text
open_ts      = startTime
OHLC         = native OHLC
volume_base  = volume
volume_quote = turnover
trade_count  = NULL, если API не предоставляет
```

---

## 6. Часовая свеча

Для `candles_1h_paper_test`:

```text
interval = '1h'
open_ts = начало UTC-часа
close_ts = open_ts + 1 hour
is_closed = true
quality_status = 'COMPLETE'
```

Текущий открытый час не сохранять.

Источники:

```text
Binance REST native 1h
Bybit REST native 1h
```

Часовые свечи скачивать напрямую с бирж. Не строить основную таблицу `1h` из минутных свечей.

Поля:

```text
OHLC — значения native 1h
volume_base — настоящий базовый объём
volume_quote — настоящий quote volume / turnover
```

Запрещено рассчитывать:

```text
volume_quote = close × volume_base
```

---

## 7. Контроль OHLC

Для каждой строки обязательно:

```text
open > 0
high > 0
low > 0
close > 0

high >= open
high >= close
high >= low

low <= open
low <= close

volume_base >= 0
volume_quote >= 0
```

Timestamp должен быть выровнен:

```text
1m — секунда и микросекунда равны 0
1h — минута, секунда и микросекунда равны 0
timezone — UTC
```

---

## 8. Источник и checksum

Примеры `source`:

```text
binance_rest_1m
binance_rest_1h
bybit_rest_1m
bybit_rest_1h
```

`source_event_id`:

```text
<exchange>:<symbol>:<interval>:<open_ts_epoch_ms>
```

`source_contract_version`:

```text
paper-candles-v1
```

Checksum рассчитывать из:

```text
exchange
symbol
interval
open_ts
close_ts
open
high
low
close
volume_base
volume_quote
trade_count
```

Один и тот же формат должен использоваться для обеих бирж.

---

## 9. Повторная загрузка

При существующем ключе:

```text
checksum совпадает
→ ничего не менять

checksum отличается
→ не перезаписывать строку молча
→ записать конфликт в отчёт
```

Backfill должен быть:

```text
идемпотентным
возобновляемым
с checkpoint
с retry и backoff
без burst-нагрузки на API
```

---

## 10. Проверка после загрузки

Для каждой таблицы отдельно вернуть:

```text
строки по exchange и symbol
минимальный open_ts
максимальный open_ts
дубли
пропущенные интервалы
NULL в обязательных полях
незакрытые свечи
неправильные timestamps
ошибки OHLC
нулевой или отрицательный объём
конфликты checksum
```

Ожидаемый календарь:

```text
1m — одна свеча на каждую UTC-минуту
1h — одна свеча на каждый UTC-час
```

Не создавать искусственные свечи для отсутствующих интервалов.

---

## 11. Проверка с биржами

Проверить минимум:

```text
BTCUSDT
ETHUSDT
SOLUSDT
XRPUSDT
DOGEUSDT
```

Для обеих бирж сравнить:

```text
последние 12 закрытых 1m
12 выбранных закрытых 1h
```

Поля:

```text
open_ts
open
high
low
close
volume_base
volume_quote
```

Все расхождения вывести отдельно.

Также собрать последние закрытые часы из 60 загруженных `1m` и сравнить с native `1h`. Это только контроль, а не замена native `1h`.

## 12. Доступ проекта

Использовать роль:

```text
paper_market_reader
```

Выдать только:

```sql
GRANT SELECT ON public.candles_1m_paper_test TO paper_market_reader;
GRANT SELECT ON public.candles_1h_paper_test TO paper_market_reader;
```

Проверить отсутствие:

```text
INSERT
UPDATE
DELETE
TRUNCATE
CREATE
```

DSN и пароль не сохранять в Git или Markdown.
