```bash
python - <<'PY'
import re
import subprocess
from pathlib import Path

accepted_base = "75608fea3a3856939281b6b444862385268142ad"

checked_versions = set()
checked_files = []

for path in sorted(Path("migrations").iterdir()):
    match = re.match(r"^(\d+)", path.name)

    if not path.is_file() or match is None:
        continue

    version = int(match.group(1))

    if version <= 16:
        subprocess.run(
            [
                "git",
                "diff",
                "--exit-code",
                accepted_base,
                "--",
                str(path),
            ],
            check=True,
        )
        checked_versions.add(version)
        checked_files.append(path.name)

expected_versions = set(range(1, 17))

assert checked_versions == expected_versions, {
    "expected": sorted(expected_versions),
    "actual": sorted(checked_versions),
    "files": checked_files,
}

print("MIGRATIONS_001_016_UNCHANGED=PASS")
print("CHECKED_VERSIONS=" + ",".join(map(str, sorted(checked_versions))))
for filename in checked_files:
    print("CHECKED_FILE=" + filename)
PY
```

Проверь checksums:

```bash
python - <<'PY'
import asyncio
import os
from pathlib import Path

import asyncpg

from paper_engine.migrations import discover_migration_bundles


async def main() -> None:
    bundles = discover_migration_bundles(Path("migrations"))

    connection = await asyncpg.connect(
        os.environ["PAPER_DATABASE_MIGRATOR_DSN"]
    )

    try:
        rows = await connection.fetch(
            """
            SELECT version, checksum
            FROM schema_migrations
            ORDER BY version
            """
        )
    finally:
        await connection.close()

    recorded = {
        int(row["version"]): str(row["checksum"])
        for row in rows
    }

    assert len(recorded) == 17
    assert sorted(recorded) == list(range(1, 18))

    for bundle in bundles:
        assert recorded[bundle.version] == bundle.checksum, {
            "version": bundle.version,
            "recorded": recorded[bundle.version],
            "computed": bundle.checksum,
        }

    print("MIGRATION_REPLAY_CHECKSUMS=PASS")


asyncio.run(main())
PY
```

# 22. First-failure правило

Expected результаты не являются failure:

```text
STAGE5G_CURSOR_OWNER_PREEXISTING_CONFLICT
permission denied for table paper_accounts
```

При первом настоящем несоответствии:

```text
остановить дальнейшие проверки
собрать diagnostics
выполнить cleanup
вернуть FAIL
```

Отчёт при FAIL:

```text
failed PHASE
failed command
expected result
actual result
completed sections
not-executed sections
diagnostics
cleanup proof
```

Верни `PASS` только после полного выполнения всех фаз и cleanup.

После отчёта остановись. Stage 5G runtime не начинать.
