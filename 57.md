## 7. Cluster B — SECURITY DEFINER collision

Cluster B должен быть новым чистым PostgreSQL-кластером.

До начала доказать:

```text
paper_stage5g_cursor_owner absent
stage5g_preexisting_attacker absent
```

Создай database:

```text
stage5g_preexisting_definer
```

Примени только migrations 001–016.

Создай:

```sql
CREATE ROLE paper_stage5g_cursor_owner
  NOLOGIN NOINHERIT NOSUPERUSER NOCREATEDB NOCREATEROLE
  NOREPLICATION NOBYPASSRLS;

CREATE ROLE stage5g_preexisting_attacker
  NOLOGIN NOINHERIT NOSUPERUSER NOCREATEDB NOCREATEROLE
  NOREPLICATION NOBYPASSRLS;

GRANT USAGE ON SCHEMA public TO paper_stage5g_cursor_owner;
GRANT USAGE ON SCHEMA public TO stage5g_preexisting_attacker;

CREATE FUNCTION public.stage5g_preexisting_probe()
RETURNS BIGINT
LANGUAGE sql
SECURITY DEFINER
SET search_path = pg_catalog, public
AS $$ SELECT count(*) FROM public.paper_accounts $$;

GRANT CREATE ON SCHEMA public TO paper_stage5g_cursor_owner;

ALTER FUNCTION public.stage5g_preexisting_probe()
  OWNER TO paper_stage5g_cursor_owner;

REVOKE CREATE ON SCHEMA public
  FROM paper_stage5g_cursor_owner;

GRANT EXECUTE ON FUNCTION
  public.stage5g_preexisting_probe()
  TO PUBLIC;
```

До migration 017 выполни probe под attacker.

Ожидается:

```text
non-zero exit code
permission denied for table paper_accounts
```

Подтверди, что attacker формально имеет EXECUTE на probe.

Попытайся применить migration 017.

Ожидается:

```text
non-zero exit code
STAGE5G_CURSOR_OWNER_PREEXISTING_CONFLICT
```

После rollback доказать:

```text
version 17 absent
Stage 5G cursor function absent
old probe function still exists
owner CREATE ON public = false
owner SELECT paper_trades = false
owner SELECT paper_accounts = false
owner SELECT funding_charges = false
```

Повторно выполни probe под attacker.

Ожидается:

```text
non-zero exit code
permission denied for table paper_accounts
```

Это доказывает, что migration не активировала старую SECURITY DEFINER функцию.

После проверки полностью удалить Cluster B вместе с volume.

## First-failure правило

При первом реальном несоответствии:

```text
остановить последующие проверки
сохранить diagnostics
выполнить cleanup
вернуть FAIL
```

Expected collision errors не являются failure:

```text
STAGE5G_CURSOR_OWNER_PREEXISTING_CONFLICT
permission denied for table paper_accounts
```

## Итоговый отчёт

Верни только:

```text
PASS
```

если полностью прошли Cluster A, Cluster B, Cluster C, regressions, final invariants и cleanup.

При `FAIL` укажи:

```text
failed cluster
failed phase
failed command
expected result
actual result
completed sections
not-executed sections
diagnostics
cleanup proof
```

Не возвращай промежуточный отчёт после readiness или collision-тестов.

После итогового отчёта остановись. Stage 5G runtime не начинать.
