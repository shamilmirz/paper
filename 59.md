## Главный принцип

Не запускай PostgreSQL, пока полностью не проверен внешний acceptance-harness.

Весь процесс состоит из двух обязательных режимов одного harness:

```text
./run_acceptance.sh --preflight
./run_acceptance.sh --run
```

`--run` разрешён только после:

```text
HARNESS_PREFLIGHT=PASS
```

Не возвращай промежуточный отчёт после успешного preflight. После `HARNESS_PREFLIGHT=PASS` автоматически продолжай полный acceptance.

# 7. Работа без host `psql`

SQL выполнять только через PostgreSQL container.

Определи функции:

```bash
pg_psql() {
  local container="$1"
  local database="$2"
  shift 2

  docker exec -i \
    -e PGPASSWORD="$PGPASSWORD" \
    "$container" \
    psql \
      -U "$PGUSER" \
      -d "$database" \
      -v ON_ERROR_STOP=1 \
      "$@"
}

pg_createdb() {
  local container="$1"
  local database="$2"

  docker exec \
    -e PGPASSWORD="$PGPASSWORD" \
    "$container" \
    createdb \
      -U "$PGUSER" \
      "$database"
}

pg_dropdb() {
  local container="$1"
  local database="$2"

  docker exec \
    -e PGPASSWORD="$PGPASSWORD" \
    "$container" \
    dropdb \
      -U "$PGUSER" \
      --if-exists \
      "$database"
}
```

Migration runner и pytest выполняются через temporary venv на host, подключаясь к случайному published port.

# 11. Cluster B — SECURITY DEFINER collision

Применить migrations 001–016.

Создать exact роли и probe:

```sql
CREATE ROLE paper_stage5g_cursor_owner
  NOLOGIN NOINHERIT NOSUPERUSER NOCREATEDB NOCREATEROLE
  NOREPLICATION NOBYPASSRLS;

CREATE ROLE stage5g_preexisting_attacker
  NOLOGIN NOINHERIT NOSUPERUSER NOCREATEDB NOCREATEROLE
  NOREPLICATION NOBYPASSRLS;

GRANT USAGE ON SCHEMA public TO paper_stage5g_cursor_owner;
GRANT USAGE ON SCHEMA public TO stage5g_preexisting_attacker;

CREATE FUNCTION public.stage5g_preexisting_probe()
RETURNS BIGINT
LANGUAGE sql
SECURITY DEFINER
SET search_path = pg_catalog, public
AS $$ SELECT count(*) FROM public.paper_accounts $$;

GRANT CREATE ON SCHEMA public TO paper_stage5g_cursor_owner;

ALTER FUNCTION public.stage5g_preexisting_probe()
  OWNER TO paper_stage5g_cursor_owner;

REVOKE CREATE ON SCHEMA public
  FROM paper_stage5g_cursor_owner;

GRANT EXECUTE
  ON FUNCTION public.stage5g_preexisting_probe()
  TO PUBLIC;
```
